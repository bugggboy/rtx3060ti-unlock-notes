# RTX 3060 Ti 半速率锁解锁成功 — 实测结果

日期：2026-10-28
机器：i5-12400F + MSI B660M MORTAR MAX WIFI DDR4 + RTX 3060 Ti 8GB（GA104, `24c910de` / `16fb10de`）
驱动：NVIDIA 610.88，未修改、未刷 VBIOS

---

## 一、实测对比（8192³ GEMM，5 次中位数）

| 精度路径 | 解锁前 | 解锁后 | 提升 |
|---|---|---|---|
| **BF16 + FP32 累加** | 35.97 TFLOPS | **63.40 ~ 67.69** | **+76% ~ +88%** |
| **FP16 + FP32 累加** | 35.77 TFLOPS | **64.42** | **+80%** |
| **TF32 张量核心** | 17.99 TFLOPS | **32.83** | **+82%** |
| FP32（CUDA 核心） | 13.96 TFLOPS | 13.27 | 不变（符合预期） |

归一化到每 SM 每时钟：

```
解锁前  ~500 FLOP/clk/SM    ← 半速率
解锁后  ~861 FLOP/clk/SM    ← 接近专业卡 GA102 的 1024
```

## 二、EFI 写入日志证据

`F:\RTX3090-UNLOCK\AUTO000002\REPORT.TXT` 尾部：

```
post-FLR SEC2 reset released, GSP halted, BME=0 pending=0
WPR2=1ffffe00:00000000  SS0=88888888  SS1=00000008
transaction result=0 containment=0 started=1 quiesced=1 fault=0 retained=0 maps=0 FLR=1
FINAL status=0 stage=transaction attempted=1 driver_release=0 clean=1
```

- `SS0=0x88888888`、`SS1=0x00000008` — 目标值写入并在 FLR 后确认
- `attempted=1` — 真实执行过写入
- `clean=1`、`FINAL status=0` — 事务完整收尾，无残留

## 三、关键突破：两个配置错误

整晚排查的根因是**两个部署错误**，不是硬件或固件问题：

### 1. 包装层漏了本地 profile 宏（核心）

```diff
- clang ... -DGU_FULL_UNLOCK -DGU_AUTOMATIC_BOOT -DGU_HEADLESS_RESEARCH -DGU_SINGLE_RTX_CONSOLE
+ clang ... 同上 + -DGU_PROFILE_LOCAL
```

`machine-profile.h` 只有定义了 `GU_PROFILE_LOCAL` 才会包含生成的 `profile-local.h`，
否则回落到默认的 **3090** 身份（`0x220410de` / `0x88701043`）。

后果：`GuPeekCold` 拿 3090 的 ID 去匹配这块 3060 Ti，`found=0` → 返回 `EFI_NOT_FOUND`（**`0xE`**）。

> 教训：`0xE` 是 `EFI_NOT_FOUND`，`EFI_NOT_READY` 是 `0x6`。误读这个错误码，
> 让排查方向错了整整一晚（一直以为是"显卡状态不是冷的"）。

### 2. 固件资产路径

资产必须放在 **`\RTX3090-UNLOCK\ASSETS\`**（相对程序的 Parent 目录），
不是 `\ASSETS\`。5 个文件都要，且 SHA-256 必须与 `app_io.c` 内置值一致：

```
booter_load_ga102.bin        61256   056cbc064a888f80...
v67-ga102-610.43.03.bin      64000   2a0aa1f86d0b6aff...
gsp_ga10x.bin             84277400   572373620a37418f...
gsp_boot_ga102.bin           24576   3df651acb174fd5f...
gsp_boot_desc_ga102.bin         84   cc5a3fc1f4c47f2f...
```

## 五、如何再次执行

1. 完全关机（Shift + 关机），等 10 秒
2. 开机连按 **F11**
3. 选 **GPU Headless UNLOCK - EXPERIMENTAL**
4. 不按任何键，等屏幕黑掉后自动进 Windows

**解锁是易失的**：断电即失效，每次开机需重跑一次。

## 六、回滚

```powershell
# 移除启动项
bcdedit /delete {fa8c6513-d20d-11f1-a153-047c1680c782}

# 彻底撤销：删分区、空间还给 C 盘
Remove-Partition -DiskNumber 1 -PartitionNumber 4 -Confirm:$false
$p = Get-Partition -DiskNumber 1 -PartitionNumber 3
Resize-Partition -DiskNumber 1 -PartitionNumber 3 -Size ($p.Size + 2GB)
```

安全启动目前是**关闭**状态，解锁完成后建议自行恢复。

## 七、真实收益评估

| 场景 | 预期收益 |
|---|---|
| LLM 预填充（prompt 处理） | **+14% ~ +36%**（计算密集） |
| GEMM / 训练 / LoRA | **+76% ~ +88%**（本次实测） |
| SD / 扩散模型推理 | 明显提升 |
| LLM 逐 token 生成 | **≈0**（受显存带宽限制，实测 492.9 GB/s 已是上限） |
| 游戏 | 无提升（走 CUDA 核心 FP32） |

对纯 GGUF 量化推理（llama.cpp），收益接近零——因为瓶颈是显存带宽，
而 3060 Ti 的 448 GB/s 规格、实测 487.6 GB/s 已经跑满。
